プライバシー

プライバシーポリシー

ローカル翻訳を使用する場合、クエリはデバイスに残ります。オンライン翻訳を使用するか、外部検索エンジンを開くかを選択します。

拡張機能が使用するもの

Web ツールは、現在のページにクエリと編集可能な翻訳を保持します。この拡張機能は、サポートされている検索 URL とクエリを読み取り、検索 URL を変換して構築するかどうかを決定します。

この Web サイトにはユーザー アカウントがなく、クエリ履歴も保存されません。この拡張機能は、設定、最近のターゲット言語、および最近のアクションのフィードバックをブラウザーのストレージにローカルに保存します。

サイトの統計と検索のプライバシー

このサイトは Cloudflare 公式の Web Analytics を使用してアクセス数とページの表示性能を計測します。アプリや拡張機能には独自の利用状況計測、広告識別子、サイト間追跡、サーバー側の検索履歴データベースを追加しません。検索語をサイト自身の URL、Cookie、ローカルストレージに保存しません。

サードパーティのサービス

デバイス上の翻訳では、ブラウザの翻訳モデルと言語検出モデルが使用されます。ブラウザはモデル ファイルをダウンロードする場合があります。クエリ テキストはローカルで処理されます。 Google オンラインを選択した場合にのみ、Web ツールはクエリを Google に送信します。この拡張機能は Microsoft Bing を使用し、フォールバックとして Google を使用します。検索を開くと、そのクエリが選択したエンジンに送信されます。プロバイダーは独自のポリシーを適用します。 CloudflareはこのWebサイトをホストしており、IPアドレスやリクエスト時間などのネットワークおよびセキュリティのログを保持する場合があります。ホスティング ログは、製品使用状況の追跡とは別のものです。 検索語を翻訳する前に、拡張機能のポップアップでオンライン翻訳を許可してください。
