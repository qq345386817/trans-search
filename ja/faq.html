言語横断検索: 質問と回答

検索前のクエリの翻訳に関する実践的な回答。

言語横断検索とは何ですか?

これは、別の言語のクエリを使用して情報を検索することを意味します。たとえば、Google や Bing で検索する前に、中国語の技術的な質問を英語に翻訳します。結果は検索エンジンによって異なります。英語の表現は英語のみの結果を保証するものではありません。

Google または Bing の検索クエリを翻訳するにはどうすればよいですか?

クエリを入力し、そのソース言語とターゲット言語、および検索エンジンを選択します。この Web サイトではローカル翻訳がデフォルトです。必要に応じて、オンラインで Google を明示的に選択します。文言を確認または編集して、翻訳された検索を開きます。元の検索は引き続き利用できます。

これは結果ページ全体を翻訳するのでしょうか?

いいえ、Translate & Search が検索クエリを翻訳します。そのクエリに対して選択した検索エンジンが開きますが、結果ページ全体を埋め込んだり、収集したり、翻訳したりすることはありません。

アカウントは必要ですか? 検索履歴は保存されますか?

アカウントは必要ありません。また、この Web サイトはクエリ履歴を保存したり、使用状況の追跡を追加したりしません。ローカル翻訳はデバイス上のテキストを処理します。 Google はオンライン翻訳を選択した場合にのみ処理します。検索エンジンは、ユーザーが開くと検索を処理します。ホスティング ネットワークとセキュリティ ログが存在する可能性があります。

アプリと拡張機能の違いは何ですか?

Web ツールは、ここに入力したクエリを翻訳します。 Safari および Chromium 拡張機能は、サポートされている検索結果ページからのクエリを自動または手動で翻訳できます。コンパニオン Apple アプリは、Safari 拡張機能を有効にするのに役立ちます。アプリと拡張機能は現在開発中であり、正式にはリリースされていません。

技術的なクエリの翻訳を改善するにはどうすればよいですか?

API 名、製品名、モデル番号、エラー メッセージは、必要に応じて変更しないでください。検索する前に翻訳を確認してください。簡潔なキーワードを試し、元のクエリと翻訳されたクエリを比較してください。機械翻訳はより良い結果を保証するものではありません。

翻訳が失敗した場合はどうなりますか?

ローカル モードでは、ソース言語を選択するか、サポートされているデスクトップ ブラウザを試してください。オンラインで Google を明示的に選択したり、原文を検索したり、独自の翻訳を入力したりできます。ローカルでエラーが発生した場合、テキストは自動的にアップロードされません。オンライン リクエストは一時的な障害に対して 1 回再試行し、その後手動で回復します。 Google のウェブ エンドポイントにはサービス保証がありません。
