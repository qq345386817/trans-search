無料のオンラインクエリ翻訳

検索語を翻訳して、他の言語の情報を探す。

編集可能なクエリ翻訳と好みの検索エンジンを使用して、別の言語で情報を検索します。

検索語の翻訳ツール

オリジナルを検索

翻訳されたクエリを検索する

クエリは翻訳のためにこのデバイスに保存されます。サポートされているデスクトップ ブラウザは、最初に言語モデルをダウンロードする場合があります。ローカル翻訳が利用できない場合は、オンライン翻訳を明示的に選択するか、自分で翻訳を入力してください。

例を試してみる

ローカル翻訳は検索語を端末上で処理します。Google オンラインを選ぶと Google に送信されます。検索リンクを開くと、選択した検索エンジンに送信されます。アカウントは不要で、検索履歴は保存しません。サイトのアクセス数と表示性能は Cloudflare Web Analytics で計測します。

これにより、結果ページではなくクエリが翻訳されます。利用可能な翻訳サービスは状況によって異なる場合があります。

なぜこれが存在するのか

有用な情報はウェブ上に均等に配布されていません。トピックによっては、別の言語で説明したほうが適切な場合もあり、1 つの言語だけで検索しても良好な結果が得られる場合があります。

検索する前に翻訳して確認する

ここにクエリを入力し、Google、Bing、Baidu、または Sogou を開く前に翻訳を確認してください。オンライン ツールを使用するために拡張機能は必要ありません。

元の検索と翻訳された検索を比較する

比較が必要な場合は、どちらかの文言を検索してください。翻訳を確認し、重要な技術名は変更しないでください。

言語と検索エンジンを選択してください

英語、中国語、日本語などに翻訳し、Google、Bing、Baidu、または Sogou を選択して調査を続けます。

サポートされている検索ページ

この Web サイトでは、拡張機能なしで Google、Bing、Baidu、Sogou 検索を開くことができます。コンパニオン アプリと Safari/Chromium 拡張機能は開発中で、サポートされているブラウザの検索ページで直接翻訳を提供します。
