Quick guide: setup and everyday use

Use the online tool now, or follow these steps when testing the app and browser extension. The app and extension have not officially launched.

Start quick test Back to home

Get started in 30 seconds

  1. The app and extension are in development. Contact us about a test version or obtain the source. In Safari, enable the extension in Safari settings before testing.
  2. Open Google, Bing, Baidu, or Sogou.
  3. Review online translation permission in the extension popup before translating search queries. Choose your target language in the popup.
  4. Leave auto-translate on and try one normal search, or use manual translate once if you want a quick first success.

Core controls

  • Target language: choose which language the query should be translated into.
  • Open results in: current tab or new tab.
  • Skip same language: avoid translating when the query already looks like the target language.
  • Ignored languages: keep auto-translate from running on selected query languages.
  • Site mode: keep a site in manual-only mode if you do not want automatic translation there.

Try it on a supported search page

For the smoothest first run, start here:

  1. Open Google first if you just want the most reliable first test.
  2. Review online translation permission in the extension popup before translating search queries. Open the popup and choose your target language.
  3. Translate the current search from the popup, or run another search with automatic translation enabled. Check that the query shown on the result page changes to its translation.

Want a different engine? Use the quick links below. Bing, Baidu, and Sogou are ready too.
