개인 정보 보호 정책

로컬 번역을 사용할 때 쿼리는 장치에 유지됩니다. 온라인 번역을 사용할지 아니면 외부 검색 엔진을 열지 선택합니다.

확장 프로그램이 사용하는 것

웹 도구는 현재 페이지에 쿼리와 편집 가능한 번역을 보관합니다. 확장 프로그램은 지원되는 검색 URL과 쿼리를 읽어 검색 URL을 번역하고 구축할지 여부를 결정합니다.

웹사이트에는 사용자 계정이 없으며 쿼리 기록을 저장하지 않습니다. 확장 프로그램은 기본 설정, 최근 대상 언어 및 최근 작업 피드백을 브라우저 저장소에 로컬로 저장합니다.

웹사이트 통계와 검색 개인정보 보호

이 웹사이트는 Cloudflare 공식 Web Analytics로 방문 및 페이지 성능을 측정합니다. 앱과 확장 프로그램에 자체 사용 추적, 광고 식별자, 사이트 간 추적 또는 서버 검색 기록 데이터베이스를 추가하지 않습니다. 검색어를 웹사이트 자체 URL, 쿠키 또는 로컬 저장소에 기록하지 않습니다.

제3자 서비스

기기 내 번역은 브라우저의 번역 및 언어 감지 모델을 사용합니다. 브라우저는 모델 파일을 다운로드할 수 있습니다. 쿼리 텍스트는 로컬로 처리됩니다. Google 온라인을 선택한 경우에만 웹 도구가 Google에 검색어를 보냅니다. 확장 프로그램은 대체 수단으로 Google과 함께 Microsoft Bing을 사용합니다. 검색을 열면 해당 쿼리가 선택한 엔진으로 전송됩니다. 공급자는 자체 정책을 적용합니다. Cloudflare는 이 웹사이트를 호스팅하며 IP 주소, 요청 시간 등의 네트워크 및 보안 로그를 보관할 수 있습니다. 호스팅 로그는 제품 사용 추적과 별개입니다.
