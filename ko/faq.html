언어 간 검색: 질문과 답변

검색 전 쿼리 번역에 대한 실용적인 답변입니다.

언어 간 검색이란 무엇입니까?

이는 다른 언어로 된 쿼리로 정보를 검색하는 것을 의미합니다. 예를 들어, Google이나 Bing을 검색하기 전에 중국어 기술 질문을 영어로 번역하세요. 결과는 검색 엔진에 따라 다릅니다. 영어 표현이 영어로만 이루어진 결과를 보장하지는 않습니다.

Google 또는 Bing 검색어를 어떻게 번역하나요?

쿼리를 입력하고 소스 및 타겟 언어와 검색 엔진을 선택하세요. 이 웹사이트에서는 현지 번역이 기본입니다. 필요한 경우 명시적으로 Google 온라인을 선택하세요. 문구를 검토하거나 편집한 다음 번역된 검색을 엽니다. 원래 검색은 계속 사용할 수 있습니다.

전체 결과 페이지가 번역됩니까?

아니요. Translate & Search는 검색어를 번역합니다. 해당 검색어에 대해 선택한 검색 엔진을 열고 전체 결과 페이지를 포함하거나 스크랩하거나 번역하지 않습니다.

계정이 필요합니까? 검색 기록이 저장됩니까?

계정이 필요 없으며 검색 기록을 저장하지 않습니다. 로컬 번역은 기기에서 처리하며 온라인 번역을 선택할 때만 Google로 전송합니다. 검색을 열면 선택한 검색 엔진이 검색어를 처리합니다. 웹사이트는 Cloudflare Web Analytics로 방문 및 성능을 측정하며 호스팅 서비스의 네트워크 및 보안 로그가 남을 수 있습니다.

앱과 확장 프로그램의 차이점은 무엇인가요?

웹 도구는 여기에 입력한 쿼리를 번역합니다. Safari 및 Chromium 확장 프로그램은 지원되는 검색 결과 페이지의 쿼리를 자동 또는 수동으로 번역할 수 있습니다. 동반 Apple 앱은 Safari 확장 기능을 활성화하는 데 도움이 됩니다. 앱과 확장 프로그램은 현재 개발 중이며 공식적으로 출시되지 않았습니다.

기술적인 쿼리 번역을 어떻게 개선할 수 있나요?

적절한 경우 API 이름, 제품 이름, 모델 번호 및 오류 메시지를 변경하지 않고 유지하십시오. 검색하기 전에 번역을 검토하세요. 간결한 키워드를 사용해보고 원본 검색어와 번역된 검색어를 비교해 보세요. 기계 번역은 더 나은 결과를 보장하지 않습니다.

번역이 실패하면 어떻게 되나요?

로컬 모드에서 소스 언어를 선택하거나 지원되는 데스크톱 브라우저를 사용해 보세요. 명시적으로 Google 온라인을 선택하거나, 원본을 검색하거나, 직접 번역을 입력할 수 있습니다. 로컬 오류는 텍스트를 자동으로 업로드하지 않습니다. 온라인 요청은 일시적인 오류에 대해 한 번 재시도한 후 수동 복구를 제공합니다. Google의 웹 엔드포인트에는 서비스가 보장되지 않습니다.
