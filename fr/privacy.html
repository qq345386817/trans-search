Confidentialité

Politique de confidentialité

Les requêtes restent sur votre appareil lorsque vous utilisez la traduction locale. Vous choisissez d'utiliser la traduction en ligne ou d'ouvrir un moteur de recherche externe.

Ce que l'extension utilise

L'outil Web conserve votre requête et votre traduction modifiable dans la page actuelle. L'extension lit les URL de recherche et les requêtes prises en charge pour décider s'il faut traduire et créer une URL de recherche.

Le site Web n'a pas de compte d'utilisateur et n'enregistre pas l'historique des requêtes. L'extension enregistre les préférences, les langues cibles récentes et les commentaires sur les actions récentes localement dans le stockage du navigateur.

Pas de suivi d'utilisation

Ce site Web et cette application n'ajoutent pas d'analyses d'utilisation, d'identifiants publicitaires, de suivi intersites ou de base de données d'historique de recherche côté serveur. Le site Web n'écrit pas de requêtes dans ses propres URL, cookies ou stockage local.

Services tiers

La traduction sur l'appareil utilise les modèles de traduction et de détection de langue du navigateur. Le navigateur peut télécharger des fichiers de modèle ; le texte de la requête est traité localement. Ce n'est que lorsque vous choisissez Google en ligne que l'outil Web envoie la requête à Google. L'extension utilise Microsoft Bing, avec Google comme solution de secours. L'ouverture d'une recherche envoie sa requête au moteur sélectionné. Les fournisseurs appliquent leurs propres politiques. Cloudflare héberge ce site Web et peut conserver des journaux de réseau et de sécurité tels que les adresses IP et les heures de demande. Les journaux d'hébergement sont distincts du suivi de l'utilisation du produit.
