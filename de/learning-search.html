Beispiele für eine sprachübergreifende Suche

Finden Sie Lernressourcen in einer anderen Sprache

Finden Sie eine andere Perspektive auf ein Thema, ohne eine Erweiterung zu installieren. Beginnen Sie mit einer kurzen Abfrage und überprüfen Sie die Übersetzung, bevor Sie die Ergebnisse öffnen.

Ein dreistufiger Workflow

  1. Benennen Sie das Thema und Ihr Niveau: Anfänger, Einführung oder Fortgeschritten. Vermeiden Sie es, persönliche Daten in die Abfrage einzugeben.
  2. Wählen Sie eine Sprache, die Sie erkunden möchten. Überprüfen Sie das übersetzte Thema und behalten Sie die mathematische Notation und die Produktnamen bei.
  3. Vergleichen Sie mehrere Ressourcen. Überprüfen Sie, wer sie veröffentlicht hat, welche Voraussetzungen sie erfüllen und ob ihre Beispiele Ihren Anforderungen entsprechen.
