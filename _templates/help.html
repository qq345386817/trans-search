Quick guide: setup and everyday use

Install, enable, open one supported search page, and get to your first successful translation in about 30 seconds.

Start quick test Back to home

Get started in 30 seconds

  1. Install Translate & Search and enable it in Safari.
  2. Open Google, Bing, Baidu, or Sogou.
  3. Choose your target language in the popup.
  4. Leave auto-translate on and try one normal search, or use manual translate once if you want a quick first success.

Core controls

  • Target language: choose which language the query should be translated into.
  • Open results in: current tab or new tab.
  • Skip same language: avoid translating when the query already looks like the target language.
  • Ignored languages: keep auto-translate from running on selected query languages.
  • Site mode: keep a site in manual-only mode if you do not want automatic translation there.

Try it on a supported search page

For the smoothest first run, start here:

  1. Open Google first if you just want the most reliable first test.
  2. Open the popup and choose your target language.
  3. Run one normal search. Success means the results reopen in that target language.
