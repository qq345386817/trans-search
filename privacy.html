Privacy

Privacy policy

Queries stay on your device when using local translation. You choose whether to use online translation or open an external search engine.

What the extension uses

The web tool holds your query and editable translation in the current page. The extension reads supported search URLs and queries to decide whether to translate and build a search URL.

The website has no user accounts and does not save query history. The extension saves preferences, recent target languages, and recent action feedback locally in browser storage.

Website statistics and query privacy

The website uses official Cloudflare Web Analytics to measure visits and page performance. We do not add custom app or extension usage tracking, advertising identifiers, cross-site tracking, or a server-side search-history database. The website does not write queries into its own URLs, cookies, or local storage.

Third-party services

On-device translation uses the browser’s translation and language-detection models. The browser may download model files; query text is processed locally. Only when you choose Google online does the web tool send the query to Google. The extension uses Microsoft Bing, with Google as a fallback. Opening any search sends its query to the selected engine. Providers apply their own policies. Cloudflare hosts this website and may retain network and security logs such as IP addresses and request times. Hosting logs are separate from product usage tracking. Review online translation permission in the extension popup before translating search queries.

Contact

For privacy questions, support requests, or policy updates, contact cameoshell09@gmail.com.

This page is a practical product privacy page. If the app later adds new services or new data flows, this policy should be updated accordingly.
