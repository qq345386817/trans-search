번역된 검색어 검색

귀하의 검색어는 번역을 위해 이 기기에 보관됩니다. 지원되는 데스크탑 브라우저는 언어 모델을 먼저 다운로드할 수 있습니다. 현지 번역을 사용할 수 없는 경우 명시적으로 온라인 번역을 선택하거나 직접 번역을 입력하세요.

예시를 들어보세요

로컬 번역은 검색어를 기기에서 처리합니다. Google 온라인을 선택하면 Google로 전송됩니다. 검색 링크를 열면 선택한 검색 엔진으로 전송됩니다. 계정이 필요 없으며 검색 기록을 저장하지 않습니다. 웹사이트 방문 및 페이지 성능은 Cloudflare Web Analytics로 측정합니다.

이는 결과 페이지가 아닌 쿼리를 번역합니다. 번역 서비스 이용 가능 여부는 달라질 수 있습니다.

이것이 존재하는 이유

유용한 정보는 웹 전체에 고르게 배포되지 않습니다. 일부 주제는 다른 언어로 더 잘 다루어지며, 한 가지 언어로만 검색하면 좋은 결과를 얻을 수 있습니다.

검색하기 전에 번역하고 검토하세요.

여기에 쿼리를 입력하고 Google, Bing, Baidu 또는 Sogou를 열기 전에 번역을 검토하세요. 온라인 도구를 사용하는 데는 확장이 필요하지 않습니다.

원본 검색어와 번역된 검색어 비교

비교가 필요할 때 두 단어 중 하나를 검색하세요. 번역을 검토하고 중요한 기술 이름을 변경하지 않고 유지하세요.

언어와 검색 엔진을 선택하세요

영어, 중국어, 일본어 등으로 번역한 다음 Google, Bing, Baidu 또는 Sogou를 선택하여 연구를 계속하세요.

지원되는 검색 페이지

웹사이트는 확장 프로그램 없이 Google, Bing, Baidu 및 Sogou 검색을 열 수 있습니다. 컴패니언 앱과 Safari/Chromium 확장 프로그램은 개발 중이며 지원되는 브라우저 검색 페이지에서 직접 번역을 제공합니다.

일상적인 브라우저 작업 흐름에서 사용하세요

앱과 브라우저 확장이 개발 중입니다. 지원되는 Safari 및 Chromium 검색 페이지에 자동 및 수동 쿼리 번역을 제공합니다. 가이드를 읽어보시거나 테스트에 관해 문의해 주세요.
